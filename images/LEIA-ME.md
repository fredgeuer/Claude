# Imagens do site

Coloque aqui as imagens com **exatamente** estes nomes. Enquanto um arquivo
não existir, o site mostra um espaço reservado com a descrição da imagem.

| Arquivo | Onde aparece | Formato sugerido |
|---|---|---|
| `mockup.png` | Hero, "Tudo o que você vai receber" e card de preço (pranchas empilhadas) | 4:3, ~1600×1200 |
| `metodo1.png` … `metodo4.png` | Cards de "Como o kit funciona" | 16:10, ~1200×750 |
| `galeria1-cor.png` … `galeria6-cor.png` | Galeria: página real colorida | 3:4, ~900×1200 |
| `galeria1-pb.png` … `galeria6-pb.png` | Galeria: mesma página em P&B | 3:4, ~900×1200 |
| `depoimento1.png` … `depoimento3.png` | Carrossel de depoimentos (prints) | 9:14, ~900×1400 |
| `bonus1.png` … `bonus4.png` | Capas dos bônus | 3:4, ~600×800 |
| `og-image.png` | Imagem de compartilhamento (WhatsApp/redes) | 1200×630 |
| `favicon.ico` | Ícone da aba do navegador | 32×32 |

Dica: exporte em `.png` ou converta para `.webp` (mais leve) e troque a extensão no `index.html`.
